# «مطرحك ميدان» — تطبيق الموظف (Flutter)
**من البلاغ إلى الحل.**

هذا تطبيق الفرق الميدانية في منصة «مطرحك». يستلم فيه الموظف البلاغات المسندة إليه أو بلاغات مديريته، ويتوجه إلى موقعها، ويحدّث حالتها، ويتواصل مع المواطن، ويوثّق الإنجاز بالصور حتى الحل.
التطبيق مربوط بالـ API الحقيقي (Laravel — مجلد `smart-city-api`) ولا يحتوي أي بيانات وهمية.

## كيف يختلف عن تطبيق المواطن
| | تطبيق المواطن «مطرحك» | تطبيق الموظف «مطرحك ميدان» |
|---|---|---|
| الاسم على الهاتف | مطرحك | مطرحك ميدان |
| الأيقونة | شعار مطرحك على خلفية بيضاء | الأيقونة الخضراء الداكنة (النسر والدبوس) بخلفية كاملة |
| الألوان | أخضر فاتح، أشرطة بيضاء | أشرطة علوية وسفلية بالأخضر الليلي، أزرار فيروزية، ولمسات ذهبية |
| شاشة الإقلاع | بيضاء | داكنة بلون الأيقونة (وعلى Android 12+ أيضاً) |
| معرّف التطبيق (applicationId) | `sy.gov.matrahak.matrahak_citizen` | `sy.gov.matrahak.matrahak_employee` |

**التطبيقان يُثبَّتان معاً على نفس الهاتف.** لكل منهما جلسة وتخزين منفصلان.
وحساب المواطن مرفوض في تطبيق الموظف، والعكس كذلك، برسالة واضحة من الخادم.

## المتطلبات
- Flutter **3.35 أو أحدث** (نفّذ `flutter --version` للتأكد). تم فحص الكود على **3.35.7** و **3.47.7**.
- محاكي Android أو هاتف حقيقي (أو Windows / Chrome للتجربة السريعة).
- خادم Laravel يعمل (الدفعات 1–3).

## التشغيل
**1) على المحاكي:** شغّل Laravel:
```
cd C:\Users\SOLAV\smart-city-api
php artisan serve --host=0.0.0.0 --port=8000
```
ثم في نافذة ثانية:
```
cd C:\Users\SOLAV\matrahak_employee
flutter run
```
- محاكي Android يصل للكمبيوتر عبر `http://10.0.2.2:8000`، وهذا هو العنوان الافتراضي.
- على Windows / Chrome العنوان الافتراضي `http://127.0.0.1:8000`.

**2) على هاتف حقيقي:** نفس خطوات تطبيق المواطن.
1. وصّل الهاتف والكمبيوتر بنفس شبكة Wi-Fi.
2. اعرف IP الكمبيوتر بالأمر `ipconfig`.
3. ضع `APP_URL=http://IP:8000` في `.env` ثم نفّذ `php artisan config:clear`.
4. في شاشة الدخول اضغط «تغيير الخادم».

**الحسابات التجريبية** (كلمة المرور لكل الموظفين `Employee@1234`):

| الحساب | المديرية | المحافظة |
|---|---|---|
| `employee.mun@matrahak.sy` | الخدمات والصيانة | دمشق |
| `employee.elec@matrahak.sy` | الكهرباء | دمشق |
| `employee.water@matrahak.sy` | المياه والصرف الصحي | دمشق |

- النمط نفسه لباقي المديريات: `employee.traffic`، `env`، `safety`، `telecom`، `health`.
- في حلب: `employee.mun.aleppo@matrahak.sy` و `employee.elec.aleppo@matrahak.sy`.
- في وضع التطوير يظهر زر يعبّئ حساب `employee.mun` تلقائياً.
- حسابات المدراء (`manager@matrahak.sy` / `Manager@1234`) تدخل أيضاً. لكنها غير مرتبطة بمديرية، فيظهر تنبيه واضح بدل قائمة القسم والخريطة.

## الشاشات والميزات
| الشاشة | ما تفعله (كلها من الـ API الحقيقي) |
|---|---|
| البداية والدخول | الدخول بالبريد الوظيفي **أو** رقم الجوال. الحساب الموقوف يخرج تلقائياً مع رسالة الإدارة. |
| الرئيسية | تحية باسم الموظف ومديريته، وعدد المفتوحة والمتأخرة وما أُسند هذا الشهر. **أولويات العمل** مرتبة بالأولوية ثم أقرب مهلة. عدد البلاغات بانتظار الاستلام. **أدائي:** المحلولة، نسبة الإنجاز، متوسط وقت الحل، تقييم المواطنين. |
| البلاغات | ثلاثة تبويبات: **المسندة إليّ** (بحث برقم البلاغ أو العنوان، وفلترة بالحالة والأولوية)، و**بانتظار الاستلام** (زر «استلام» سريع وعلامة «في محافظتك»)، و**المنجزة** (فلترة بالتاريخ مع تقييم المواطن). |
| تفاصيل البلاغ | صور المواطن، والمهلة (تتلوّن عند الاقتراب أو التأخر)، وبيانات المُبلِّغ مع زر اتصال (تُخفى في البلاغ مجهول الهوية). التحليل الآلي: الملخص، التصنيف والأولوية المقترحة، الثقة، واحتمال التكرار. الموقع مع زر «التوجه». السجل الكامل، والملاحظات الداخلية فيه مميّزة بقفل. |
| الإجراءات | **استلام**. **تحديث الحالة**: الحالات المتاحة يحددها الخادم، والملاحظة إلزامية، وفيها عبارات جاهزة. مع «تم الحل» تُرفق صور بعد المعالجة في نفس الخطوة. **ملاحظة** داخلية أو عامة. **رد على المواطن**. **صور بعد المعالجة**. **تحويل لمديرية أخرى** مع التصنيف الصحيح والسبب. |
| الخريطة | بلاغات المديرية المفتوحة مجمّعة حسب التكبير، بحلقة لونها يدل على صاحب البلاغ: فيروزي «مسند إليّ»، برتقالي «غير مستلم»، رمادي «لدى زميل». فلاتر بعدد كل فئة. «موقعي» و«أقرب بلاغ إليّ». الاستلام والتوجه من نافذة المعاينة. |
| إحصائيات المديرية | المؤشرات: الإجمالي، المفتوح، المتأخر، الحرج، نسبة الحل، الالتزام بالمهلة، متوسط وقت الحل، رضا المواطنين. أعمدة آخر 7 أيام (المرفوعة مقابل المحلولة)، والتوزيع حسب التصنيف والمحافظة. |
| الإشعارات | تعمل **بدون Firebase**: التطبيق يسأل الخادم كل 45 ثانية. البلاغ المسند الجديد يظهر برسالة وزر «عرض»، وتتحدث القوائم والرئيسية والخريطة تلقائياً. |
| حسابي والإعدادات | الملف الشخصي (الاسم، الجوال، الصورة؛ المديرية والمحافظة تحددهما الإدارة)، وتغيير كلمة المرور، والمظهر، وعنوان الخادم، والخصوصية. |

**مسار العمل الكامل كما يعمل في الخادم:**
1. يرفع المواطن بلاغاً، فيصنّفه الذكاء الاصطناعي ويُسند تلقائياً لأقل موظف عبئاً في المديرية، مع تفضيل نفس المحافظة.
2. يصل الموظفَ إشعار، فيفتح البلاغ.
3. يضغط «جاري المعالجة» ويتوجه إلى الموقع.
4. يضغط «تم الحل» ويرفق صوراً بعد المعالجة.
5. يصل المواطنَ إشعار، فيقيّم الخدمة، ويظهر التقييم للموظف في «المنجزة» وفي أدائه.

## البنية (Clean Architecture حسب الميزة — نفس بنية تطبيق المواطن)
```
lib/
├── main.dart / app.dart          ← ProviderScope + MaterialApp.router (عربي RTL، خط Cairo)
├── core/
│   ├── config/                   ← AppConfig (قواعد التحقق مطابقة لطلبات الموظف في Laravel) + AppAssets (الصور)
│   ├── network/ storage/ router/ ← Dio + رسائل عربية، الجلسة والكاش، GoRouter + StatefulShellRoute
│   ├── services/                 ← الموقع، العنوان التقريبي (Nominatim)، الاتصال والتوجه (url_launcher)
│   └── theme/ widgets/ utils/    ← هوية «مطرحك ميدان»، الويدجتات المشتركة، التواريخ بالأشهر السورية
└── features/
    ├── auth/        ← دخول الموظف واستعادة الجلسة
    ├── reports/     ← القوائم الثلاث، التفاصيل، نوافذ الإجراءات، وقناة «تغيّر بلاغ» (application/)
    ├── dashboard/   ← my-stats، workload، إحصائيات المديرية والرسوم
    ├── map/         ← خريطة المديرية (OpenStreetMap + تجميع)
    ├── lookups/ notifications/ profile/ settings/ shell/
```
- **State management:** Riverpod 3 (`Notifier` و`AsyncNotifier` و`FutureProvider`).
- **قناة «تغيّر بلاغ» (`ReportChanges`):** كل إجراء يعلن ما حدث، مثل الاستلام أو تغيير الحالة أو التحويل. وكل شاشة تقرر ما تحدّثه: القوائم، والرئيسية، والخريطة. فلا تحتاج شاشة التفاصيل أن تعرف من يعرض البلاغات.
- **الإجراءات تعيد البلاغ المحدّث من الخادم** فيظهر فوراً بلا طلب إضافي. والخطأ (مثل 422 أو 403) يظهر كرسالة دون أن يستبدل الصفحة.

## حلول المشاكل الشائعة
- **`Dependency ... requires compileSdk 36` أو تحذير NDK:** في `android/app/build.gradle.kts` ضع داخل `android { }`:
  - `compileSdk = 36`
  - `ndkVersion = "27.0.12077973"`
- **`minSdk` أقل من المطلوب:** ضع `minSdk = 24` داخل `defaultConfig { }`.
- **فشل رفع الصور أو الفيديو (413):** في `php.ini` اجعل `upload_max_filesize = 25M` و`post_max_size = 120M` ثم أعد تشغيل الخادم.
- **زر «التوجه» لا يفتح شيئاً على أندرويد:** يحتاج أي تطبيق خرائط يقبل روابط `geo:` (مثل OsmAnd أو Organic Maps أو خرائط الهاتف). بدونه تُفتح صفحة الاتجاهات في OpenStreetMap.
- **«انتهت الجلسة» بعد الدخول من جهاز آخر:** الخادم يسمح بجلسة واحدة لكل حساب في تطبيق الموظف. الدخول من جهاز جديد ينهي الجلسة القديمة، وهذا متعمد.
- **iOS (على Mac فقط):** أضف إلى `ios/Runner/Info.plist` المفاتيح:
  - `NSCameraUsageDescription`
  - `NSPhotoLibraryUsageDescription`
  - `NSMicrophoneUsageDescription`
  - `NSLocationWhenInUseUsageDescription`
