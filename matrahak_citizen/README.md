# مطرحك — تطبيق المواطن (Flutter)
**مطرحك معروف، وبلاغك متابع.**

تطبيق المواطن لمنصة «مطرحك»: رفع بلاغ بالصور والفيديو والموقع، متابعة حالته حتى الحل، الخريطة، والإشعارات.
مربوط بالـ API الحقيقي (Laravel — مجلد `smart-city-api`) ولا يحتوي أي بيانات وهمية.

## المتطلبات
- Flutter **3.35 أو أحدث** (نفّذ `flutter --version` للتأكد). تم فحص الكود على **3.35.7** و **3.47.7**.
- محاكي Android أو هاتف حقيقي (أو Windows / Chrome للتجربة السريعة).
- خادم Laravel يعمل (الدفعات 1–3). خدمة الذكاء الاصطناعي اختيارية.

## التشغيل
**1) على المحاكي:** شغّل Laravel بالطريقة المعتادة:
```
cd C:\Users\SOLAV\smart-city-api
php artisan serve --host=0.0.0.0 --port=8000
```
ثم في نافذة ثانية:
```
cd C:\Users\SOLAV\matrahak_citizen
flutter run
```
- محاكي Android يصل للكمبيوتر عبر `http://10.0.2.2:8000`، وهذا هو العنوان الافتراضي في التطبيق.
- على Windows / Chrome العنوان الافتراضي `http://127.0.0.1:8000`.

**2) على هاتف حقيقي:**
1. وصّل الهاتف والكمبيوتر بنفس شبكة Wi-Fi.
2. اعرف IP الكمبيوتر بالأمر `ipconfig` (مثلاً `192.168.1.10`).
3. في `smart-city-api\.env` ضع `APP_URL=http://192.168.1.10:8000` ثم نفّذ `php artisan config:clear`.
   هذا ضروري حتى تعمل الصور ورابط QR من الهاتف.
4. شغّل Laravel بـ `--host=0.0.0.0` كما في الأعلى.
5. في شاشة الدخول اضغط «تغيير الخادم» واكتب `http://192.168.1.10:8000`، ثم «فحص الاتصال».

**حساب تجريبي:** `citizen@matrahak.sy` / `Citizen@1234`.
في وضع التطوير يظهر زر يعبّئه تلقائياً.

## الشاشات والميزات
| الشاشة | ما تفعله (كلها من الـ API الحقيقي) |
|---|---|
| البداية | استعادة الجلسة. بدون إنترنت يكمل بالمستخدم المحفوظ. |
| الدخول / التسجيل | الدخول بالبريد **أو** رقم الجوال السوري. أخطاء الخادم (422) تظهر تحت الحقل نفسه. المحافظة اختيارية. |
| الرئيسية | ملخص بلاغاتي من `/reports/stats`، وأنواع المشكلات، وآخر البلاغات. |
| رفع بلاغ | حتى 5 صور/فيديو (الصور تُضغط قبل الرفع)، وGPS أو اختيار الموقع على الخريطة، والعنوان تلقائياً (Nominatim)، ونسبة الرفع، وإخفاء الاسم. التصنيف اختياري ويحدده الذكاء الاصطناعي. |
| بعد الرفع | رقم المتابعة، ورمز QR، ونتيجة التحليل الآلي (التصنيف، والجهة، والأولوية) بعد ثوانٍ. |
| بلاغاتي | فلترة (الكل / المفتوحة / المنتهية)، وتحميل تدريجي، وصندوق الانتظار. |
| تفاصيل البلاغ | الصور قبل/بعد المعالجة، ووسوم تحليل الصور، ومراحل البلاغ، وسجل المتابعة، وردود الجهة المختصة، والمهلة المتوقعة، والخريطة، وQR. أيضاً التقييم، والتأييد، والحذف قبل بدء المعالجة. |
| الخريطة | البلاغات القريبة (1–25 كم) مع تجميع (Clustering) حسب التكبير، والكثافة الحرارية، والمحافظات ومؤشر الخطورة، والفلاتر، والتأييد من نافذة المعاينة. الطبقات تتبع إعدادات لوحة الإدارة. |
| الإشعارات | تعمل **بدون Firebase**: التطبيق يسأل الخادم كل 45 ثانية. الإشعار الجديد يظهر كرسالة مع زر «عرض». |
| حسابي | تعديل الاسم والجوال والمحافظة والصورة، وتغيير كلمة المرور، وتسجيل الخروج. |
| الإعدادات | المظهر (فاتح/داكن/تلقائي)، وعنوان الخادم مع فحص الاتصال (`/health`)، والخصوصية، والتراخيص. |

**البلاغ بدون إنترنت (Offline Reporting):**
- إذا انقطع الاتصال أثناء الإرسال، يُحفظ البلاغ مع نسخة من صوره داخل التطبيق.
- يُرسل تلقائياً كل دقيقة، وعند العودة للتطبيق، أو بزر «أرسل الآن».
- كل بلاغ محفوظ مرتبط بصاحبه، فلا يُرسل باسم حساب آخر يسجّل الدخول على نفس الجهاز.

## البنية (Clean Architecture حسب الميزة)
```
lib/
├── main.dart / app.dart          ← ProviderScope + MaterialApp.router (عربي RTL، خط Cairo)
├── core/
│   ├── config/                   ← AppConfig: الثوابت وقواعد التحقق المطابقة لـ Laravel
│   ├── network/                  ← ApiClient (Dio) + ApiException برسائل عربية + غلاف الرد
│   ├── storage/                  ← AppStorage (shared_preferences): الجلسة، الإعدادات، الكاش
│   ├── router/                   ← GoRouter + StatefulShellRoute + إعادة التوجيه حسب الجلسة
│   ├── services/                 ← الموقع (geolocator)، العنوان (Nominatim)
│   ├── theme/ widgets/ utils/    ← الهوية، الويدجتات المشتركة، التواريخ بأسماء الأشهر السورية
└── features/<الميزة>/
    ├── domain/                   ← الكيانات + عقود المستودعات (Dart صرف)
    ├── data/                     ← تحويل JSON + تنفيذ المستودعات عبر ApiClient (Dart صرف)
    ├── application/              ← منطق التطبيق (صندوق الانتظار)
    └── presentation/             ← Riverpod Notifiers + الشاشات
```
- **State management:** Riverpod 3، باستخدام `Notifier`/`FutureProvider`.
  `StateNotifier` صار legacy في Riverpod 3، و`Notifier` بديله الرسمي بنفس الفكرة.
- **التنقل:** GoRouter مع `StatefulShellRoute.indexedStack`: كل تبويب يحتفظ بحالته.
- **الخرائط:** `flutter_map` + OpenStreetMap، بدون Google.
- **انتهاء الجلسة:** أي رد 401 يسجّل الخروج تلقائياً ويعرض «انتهت الجلسة».
- طبقتا `domain` و`data` لا تستوردان Flutter، لذلك تعمل نفس الشيفرة على Dart VM في أداة فحص الـ API.

## الفحص الذي تم على هذا الكود
- **`dart analyze` بدون أي ملاحظة على إعدادين:**
  - Flutter 3.47.7 مع أحدث الحزم (riverpod 3.4.3، go_router 17.5.0).
  - Flutter 3.35.7 مع الإصدارات التي يختارها pub له (riverpod 3.3.2، go_router 17.2.3).
- **طبقة البيانات على خادم Laravel حقيقي: 30/30 خطوة ناجحة.** شملت:
  - الدخول والتسجيل، وتعديل الملف الشخصي مع رفع صورة، وتغيير كلمة المرور.
  - رفع بلاغ بصورة (multipart)، ثم ظهور التصنيف الآلي.
  - التأييد وإلغاؤه. وفُحص التقييم (الذي يغلق البلاغ) والحذف قبل بدء المعالجة بشكل منفصل.
  - الخريطة، والكثافة، ومؤشرات المحافظة، والإشعارات، و401 بعد الخروج.
- **منطق الشاشات على الخادم الحقيقي: 47/47 فحصاً ناجحاً.** شُغّلت Riverpod Controllers نفسها بدون واجهة، وشملت:
  - استعادة الجلسة، وتسجيل الخروج التلقائي عند 401، وتصفير بيانات المستخدم السابق.
  - بلاغاتي وفلاترها، والإشعارات وعدّادها.
  - صندوق الانتظار: الحفظ دون اتصال، ثم الإرسال التلقائي عند عودته مع حذف نسخ الصور.
  - الخريطة: الفلاتر، والبحث في منطقة أخرى، والطبقات، والكثافة، ومؤشرات المحافظة.
- **اختبارات الوحدة: 26 اختباراً ناجحاً.**
  - تشمل التحقق من المدخلات، والتواريخ، والتجميع على الخريطة.
  - 9 منها على ردود API حقيقية محفوظة في `test/fixtures`.
  - إضافة إلى 4 اختبارات واجهة تعمل على جهازك بالأمر `flutter test`.
- **ما لم يُفحص هنا:** تشغيل الواجهة نفسها على جهاز، لأن بيئة الفحص لا تحوي محرك Flutter.
  جرّب الشاشات وأخبرني بأي خطأ يظهر.

## حلول المشاكل الشائعة
- **`Dependency ... requires compileSdk 36` أو تحذير NDK:** في `android/app/build.gradle.kts` ضع داخل `android { }`:
  - `compileSdk = 36`
  - `ndkVersion = "27.0.12077973"`
- **`minSdk` أقل من المطلوب:** ضع `minSdk = 24` داخل `defaultConfig { }`.
- **فشل رفع الفيديو (الخطأ «فشل رفع الملف» أو 413):** حدود PHP الافتراضية صغيرة.
  - في `php.ini` اجعل `upload_max_filesize = 25M` و`post_max_size = 120M`.
  - ثم أعد تشغيل `php artisan serve`.
- **الصور لا تظهر على الهاتف:** `APP_URL` في `.env` ما زال `127.0.0.1`. ضع IP الكمبيوتر.
- **iOS (على Mac فقط):** أضف إلى `ios/Runner/Info.plist` المفاتيح:
  - `NSCameraUsageDescription`
  - `NSPhotoLibraryUsageDescription`
  - `NSMicrophoneUsageDescription` (لتسجيل الفيديو)
  - `NSLocationWhenInUseUsageDescription`
- **خرائط OpenStreetMap:** خادم البلاطات العام مناسب للتجربة والعرض. عند النشر الواسع يُستخدم خادم بلاطات خاص؛ عدّل `osmTileUrl` في `AppConfig`.
