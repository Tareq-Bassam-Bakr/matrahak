# توثيق منصة «مطرحك»
**مطرحك معروف، وبلاغك متابع.**

منصة حكومية لإدارة بلاغات المواطنين، مدعومة بالذكاء الاصطناعي ونظم المعلومات الجغرافية.
كل ما في هذا المجلد مولَّد أو مُتحقَّق منه على الكود والقاعدة الحقيقيين، لا أمثلة مكتوبة يدوياً.
