# مطرحك — Matrahak
**مطرحك معروف، وبلاغك متابع.**

منصة حكومية لإدارة بلاغات المواطنين مدعومة بالذكاء الاصطناعي ونظم المعلومات الجغرافية (GIS).
هذا المجلد: الباك اند (Laravel 12 REST API) + لوحة الإدارة (Filament 3) — **103 اختبارات آلية ناجحة على MySQL 8.**
خدمة الذكاء الاصطناعي (Python) في مجلد مستقل: `matrahak-ai` — انظر قسم «خدمة الذكاء الاصطناعي» أدناه.

## المتطلبات
- PHP 8.2+ مع الإضافات: `gd, intl, zip, mbstring, pdo_mysql, openssl, fileinfo`
- Composer 2 — MySQL 8 أو MariaDB 10.6+ (Laragon / XAMPP)

## تثبيت جديد — Windows CMD
> نفّذ كل سطر وحده، ولا تنسخ أي تعليق مع الأمر.

```
composer install
copy .env.example .env
```
افتح `.env` وعدّل `DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD` (أنشئ القاعدة أولاً إن لم تكن موجودة)، ثم:
```
php artisan key:generate
php artisan storage:link
php artisan migrate:fresh --seed
php artisan serve --host=0.0.0.0 --port=8000
```
- في نافذة CMD ثانية للمهام المجدولة: `php artisan schedule:work`
- افتح: http://127.0.0.1:8000/admin

## الترقية من الدفعة 1
1. فك الضغط **فوق** المجلد الحالي واختر استبدال الملفات (يبقى `.env` و`vendor` كما هما).
2. في `.env` عدّل أو أضف:
```
APP_NAME="Matrahak"
TICKET_PREFIX=MTR
```
3. ثم:
```
php artisan optimize:clear
php artisan migrate:fresh --seed
```
(الحسابات تغيّرت إلى `@matrahak.sy` لذلك يلزم `migrate:fresh --seed`.)

## الترقية من الدفعة 2
1. فك ضغط ملف التحديث **فوق** مجلد المشروع الحالي، واختر استبدال الملفات.
   يبقى `.env` و`vendor` وقاعدة البيانات كما هي، ولا توجد جداول جديدة.
2. أضف في `.env` (انظر قسم «خدمة الذكاء الاصطناعي»):
```
AI_SERVICE_URL=http://127.0.0.1:8001
AI_SERVICE_KEY=نفس-قيمة-INTERNAL_API_KEY-في-matrahak-ai
```
3. ثم نفّذ:
```
php artisan optimize:clear
```

## الترقية من الدفعة 5 (دفعة التوثيق)
1. فك ضغط ملف التحديث **فوق** مجلد المشروع واختر استبدال الملفات. لا توجد جداول جديدة.
2. ثم نفّذ:
```
php artisan optimize:clear
php artisan test
```
الجديد:
- **Events/Listeners:** 9 أحداث في `app/Events` و3 مستمعين في `app/Listeners`. لعرض الربط: `php artisan event:list`.
- **تنبيهات المدراء ضمن المحافظة:** مدير حلب لا يتلقى تنبيهات دمشق.
- **إنشاء دور جديد:** كان يفشل، وصار يعمل.
- **سجل التدقيق:** صار يسجّل تغييرات الصلاحيات والإعدادات.
- **طابور حقيقي (اختياري):** ضع `QUEUE_CONNECTION=database` ثم شغّل `php artisan queue:work`. بدونه يبقى كل شيء كما هو.

## الأدوار
- **مدير النظام:** كل المحافظات وكل الصلاحيات (المستخدمون، الأدوار، الإعدادات، سجل التدقيق).
- **مدير المحافظة (مدير مدينة):** يرى بلاغات ومؤشرات وخريطة وتقارير محافظته فقط، ويدير الإسناد والمتابعة.
  المحافظة تُحدَّد من حقل «المحافظة» في صفحة المستخدم. مدير بلا محافظة يرى الكل.
- **الإسناد التلقائي:** موظف المديرية من نفس محافظة البلاغ أولاً، ثم الفريق المركزي (بلا محافظة)، ثم أي محافظة.

## خدمة الذكاء الاصطناعي (Python — مجلد matrahak-ai)
- **التشغيل:** في نافذة CMD مستقلة:
```
cd C:\Users\SOLAV\matrahak-ai
run.bat
```
  التفاصيل الكاملة في `matrahak-ai\README.md`: النموذج، والتقييم، وإعادة التدريب.
- **الربط:** المفتاح `INTERNAL_API_KEY` في `matrahak-ai\.env` يجب أن يساوي `AI_SERVICE_KEY` هنا، ثم نفّذ `php artisan config:clear`.
- **التحقق:** صفحة «إعدادات النظام» يجب أن تعرض «● تعمل» مع آخر تدريب وعدد العينات والدقة.
- **إن توقفت الخدمة:** يعمل البديل المحلي تلقائياً، وهو نفس الخوارزميات بـ PHP، فلا تتعطل المنصة.
- **تفسير القرار:** صفحة البلاغ ← «تحليل الذكاء الاصطناعي» تعرض:
  - الكلمات المفتاحية المطابقة.
  - أهم ما استند إليه النموذج.
  - التصنيفات البديلة مع احتمالها.
  - وسوم تحليل الصور تحت كل صورة.
- **إعادة التدريب:** «إعدادات النظام» ← زر «إعادة تدريب النموذج».
  - يرسل البلاغات الحقيقية الموثّقة: التي عولجت وأُغلقت، أو التي راجعت الإدارة تصنيفها.
  - النموذج الجديد لا يُعتمد إلا إذا لم يكن أضعف من الحالي بدلالة إحصائية.
  - بلاغات بيانات العرض (حسابات `demo.*`) لا تُستخدم في التدريب أبداً.
- **تصدير البيانات نفسها يدوياً:**
```
php artisan ai:export-training-data
```
  الملف الناتج: `storage/app/ai/training-*.csv`. ضعه في `matrahak-ai\data\real\` ثم شغّل `train.bat`.

## الهوية (.env)
- `BRAND_NAME` / `BRAND_OWNER`: اسم المنصة والجهة الحكومية المالكة.
- `BRAND_STATE_EMBLEM=true`: إظهار شعار الدولة في صفحة الدخول والتتبع وتقرير PDF.
  استخدام شعار الدولة مقيّد قانونياً بالجهات الرسمية: مناسب للعرض الأكاديمي، وعند النشر العام يلزم موافقة الجهة المعنية أو `false`.
- ملفات الشعار: `public/images/brand/`

## خدمات اختيارية
- `AI_SERVICE_URL` / `AI_SERVICE_KEY`: خدمة الذكاء الاصطناعي (`matrahak-ai`). بدونها يعمل البديل المحلي.
- `FIREBASE_CREDENTIALS`: Push عبر FCM. بدونه تبقى الإشعارات داخل التطبيقين.
- `APP_URL`: ضع IP جهازك (مثل `http://192.168.1.10:8000`) عند التجربة على هاتف حقيقي.
